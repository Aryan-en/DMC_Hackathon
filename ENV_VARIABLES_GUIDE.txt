================================================================================
HOW TO USE THIS GUIDE
================================================================================

1. Copy variables from above that match your needs
2. Paste into .env.local file
3. Update values as needed for your environment
4. Variables prefixed with NEXT_PUBLIC_ are exposed to browser (use for non-sensitive data)
5. Other variables are server-side only (more secure for sensitive data)
6. Restart Next.js dev server after modifying .env.local to apply changes
7. For missing critical vars, backend will use fallback values


================================================================================
IMPORTANT NOTES
================================================================================

• NEXT_PUBLIC_ prefix: These variables are exposed to the browser. Never put secrets here.
• Non-public variables: Safe for server-side secrets (backend URLs, API keys, etc.)
• Case-sensitive: Environment variable names are case-sensitive
• Restart required: Changes to .env.local require dev server restart
• .env.local overrides: Takes precedence over .env and .env.example
• Boolean values: Use "true"/"false" strings, or "0"/"1"
